# Applications

Standalone, runnable tools — as opposed to the notebooks elsewhere in this repo. Each one is a small program with a user interface that does something useful on its own.

## What's here

| Application | What it does |
|---|---|
| [CATIA V5 Knowledge Test](./Knowledge%20Tests/Catia%20V5/) | A desktop quiz app for practising CATIA V5 knowledge — 187 questions, single- and multiple-choice, with per-question explanations, scoring, and a review mode. Built with Tkinter. |

## Running these

Each application has its own README with instructions. They are plain Python with no third-party dependencies unless stated otherwise:

```bash
python main.py
```
